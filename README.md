## 🧠 A Bit About Me

I'm an AI/ML-leaning developer who genuinely enjoys the unglamorous half of building intelligent systems — the data pipelines, the evaluation harnesses, the APIs that have to survive real traffic instead of just a Jupyter cell.

Lately I've been going deeper into **LLM engineering and AI evaluation** — RAG pipelines, agentic workflows, MCP/tool-based systems — while still keeping one foot in backend development, databases, and IoT because I like knowing what's actually happening under the abstraction. Not just "the model said so," but *why* it said so, and what breaks when it's wrong.

If I had to sum it up:

> 🛠️ Build the system → 📏 Measure it → 🐛 Find what breaks → 🔁 Improve it → repeat

When I'm not doing that, I'm probably watching a movie, going down a random tech rabbit hole, or messing around with a half-formed side-project idea that may or may not survive the weekend. 🎬

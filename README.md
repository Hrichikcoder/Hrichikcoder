## About

I’m an AI/ML-focused software developer interested in the engineering around intelligent systems: clean data pipelines, model evaluation, backend services, APIs, storage, automation, and deployment.

My recent work has moved deeper into **LLM engineering and AI evaluation**, while I continue building across **data, backend systems, quantitative tools, and IoT**. I’m particularly interested in projects where the difficult part is not just training a model, but making the whole system reliable, measurable, and usable.

I’m also exploring **agentic AI, MCP/tool-based workflows, fine-tuning, and data-intensive systems**—with a focus on understanding what actually happens underneath the abstraction.

> Build the system. Measure it. Find what breaks. Improve it.

## Selected Projects

### [Quantitative Finance API](https://github.com/Hrichikcoder/Quantitative-Finance-api)
A FastAPI-based REST service for financial data analysis, technical indicators, strategy backtesting, and dashboard-driven performance analysis.

**Stack:** Python · FastAPI · REST API · SQLite · Financial Data · Backtesting

### [Algorithmic Trading Engine](https://github.com/Hrichikcoder/Python-Algorithmic-Trading-Engine)
An object-oriented backtesting framework for trend and momentum strategies with slippage, commissions, risk metrics, equity curves, and automated reporting.

**Stack:** Python · OOP · Pandas · NumPy · yfinance · Matplotlib

### [Autonomous Robot Car](https://github.com/Hrichikcoder/Line-Following-Obstacle-Avoidance-Robot-Car)
An Arduino-based system combining IR line following with ultrasonic obstacle avoidance and real-time navigation logic.

**Stack:** Arduino · C++ · IR Sensors · Ultrasonic Sensors · Embedded Logic

### [Weather App](https://github.com/Hrichikcoder/Weather-App)
A desktop weather application with live weather data, 5-day forecasts, AQI information, animated weather states, and time-of-day aware UI.

**Stack:** Python · Tkinter · Requests · OpenWeatherMap API
